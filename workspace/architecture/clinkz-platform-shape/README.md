# ClinkZ Platform Shape

## Purpose

Define the intended product shape, platform boundary, and application model of ClinkZ.

ClinkZ is currently positioned as an open IoT platform built on W3C Web of Things, where devices, services, applications, and software capabilities can be represented and interacted with as Things.

The remaining question is what the ClinkZ platform itself should contain and how business applications should be built on or integrated with it.

## Scope

This workspace covers:

* ClinkZ product positioning
* platform responsibilities and boundaries
* the relationship between ClinkZ and `clinkz-wot`
* the relationship between ClinkZ and vertical applications
* hosted and headless integration models
* the role of an application SDK and application runtime
* the role of AI in Thing onboarding and application development

This workspace does not define detailed implementation architecture, technology choices, or delivery plans.

## Status

Proposal under discussion.

## Expected Outputs

* an accepted definition of the ClinkZ platform
* an agreed platform boundary
* an application and integration model
* follow-up architecture decisions and requirements
